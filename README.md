# AI Project Learning Starter

Three standalone educational AI project templates for architecture, research-to-decisions, and simulation/evaluation. Copy a template, customize it for your permitted context, and verify all factual claims and actions.

These are **static instructions**, not an agent service, a measured performance result or permission to access external accounts. Do not enter private credentials, client data, identifiable people or confidential operating instructions into shared examples.

The three original templates and their unchanged MIT notice are reproduced with an exact-source checksum manifest. No original private Git history, internal project documentation, customer data or operational files are included.
