# AI Project Learning Starter

Three practical templates for creating clear, testable AI project instructions.

- [Project Architect](templates/project-architect.md) — define scope, operating rules, evidence and acceptance criteria.
- [Research to Decisions](templates/research-to-decisions.md) — turn research into transparent, evidence-based decisions.
- [Simulation and Evaluation](templates/simulation-and-evaluation.md) — design bounded tests and report what they do and do not prove.

Choose a template, adapt it to your authorized work, and review factual claims before relying on an output. These are static instructions, not a hosted agent, a performance guarantee, or permission to access accounts or private data. Use fictional placeholders when sharing examples.
